# Tank Battle – C++ Console Game

## Overview
Tank Battle is a console-based game developed in C++ using Visual Studio as part of an academic programming project.

The game features tank movement, shooting mechanics, obstacles, and interactive gameplay within an ASCII-based environment.

## Features
- Two-player gameplay with keyboard controls
- Tank movement and directional controls
- Shooting and collision mechanics
- Colored game interface and menus
- ASCII-based tank representation
- Explosion animation and sound effects for mines
- Support for different screen sizes within an 80×25 console display
- Game step recording and file-based functionality

## Technologies
- C++
- Visual Studio
- Windows Console
- Object-Oriented Programming (OOP)
- File Handling

## Project Structure
The project includes separate C++ source and header files for game logic, player controls, board management, menus, and file operations.

## Development Notes
The project was developed as part of a Computer Science course, incorporating concepts and techniques learned during lectures and practical exercises.

External learning resources and AI assistance were used for selected implementation details, including menu design and console colors.

## How to Run
1. Open `TankBattleGame.sln` in Visual Studio.
2. Build the solution.
3. Run the game in a Windows console.
